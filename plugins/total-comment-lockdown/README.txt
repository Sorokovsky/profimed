Total Comment Lockdown
======================

Що робить плагін
----------------
- Закриває коментарі для всіх наявних записів, сторінок, медіафайлів, PDF і користувацьких типів контенту.
- Вимикає коментарі та pingback для майбутнього контенту.
- Блокує надсилання через wp-comments-post.php.
- Вимикає маршрути коментарів у WordPress REST API.
- Вимикає XML-RPC pingback.
- Приховує старі коментарі на сайті.
- Прибирає інтерфейс коментарів з адмінки.
- Не видаляє старі коментарі з бази даних.

Встановлення
------------
1. У WordPress відкрийте: Плагіни → Додати новий плагін.
2. Натисніть «Завантажити плагін».
3. Виберіть файл total-comment-lockdown.zip.
4. Натисніть «Встановити».
5. Після встановлення натисніть «Активувати».

Важливо
-------
Перед активацією бажано зробити резервну копію бази даних.
Після деактивації плагіна раніше закриті коментарі автоматично не відкриваються.
